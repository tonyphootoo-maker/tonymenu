# LineMenuViewer 🍽️
**เว็บแอปแสดงใบเมนูอาหารสำหรับส่งทาง LINE (ฟรี 100% ไม่มีค่าใช้จ่าย)**

เว็บแอปพลิเคชันที่ออกแบบมาเพื่อร้านอาหารโดยเฉพาะ สำหรับส่งลิงก์ดูใบเมนูอาหาร (รูปภาพ JPG/PNG) ให้ลูกค้าทาง LINE ได้อย่างง่ายดาย สวยงาม คมชัด และป้องกันไม่ให้ลูกค้าเข้าไปแก้ไขแอป

---

## ✨ จุดเด่นและการทำงาน

1. **โหมดลูกค้า (Customer View)**
   - ลูกค้าจะเห็น**เฉพาะรูปใบเมนูอาหารเท่านั้น** ไม่เห็นปุ่มแก้ไข ลบ หรือเครื่องมือแอดมินใดๆ
   - รองรับการเปิดผ่านห้องแชท LINE บนมือถือได้อย่างสมบูรณ์แบบ
   - เลื่อนปัดซ้าย-ขวาเพื่อเปลี่ยนหน้า
   - มีระบบซูมภาพ (Pinch-to-zoom / Zoom In-Out) และเลื่อนดูราคาอาหารได้อย่างคมชัด
   - มีปุ่มลัดสำหรับกดสั่งอาหารทาง LINE หรือโทรหาร้านได้ทันที

2. **โหมดจัดการสำหรับเจ้าของร้าน (Admin Panel)**
   - ปลดล็อกผ่านรหัส PIN 4 หลัก (ค่าเริ่มต้นคือ `1234`)
   - **เพิ่ม/ลบ/แก้ไขใบเมนู**: อัปโหลดรูปจากเครื่อง หรือใส่ลิงก์รูปภาพจาก GitHub
   - **ระบบ Drag & Drop**: กดเม้าส์ค้างไว้ที่ใบเมนูแล้วลากวางเพื่อสลับตำแหน่งหน้าได้ทันที (หรือกดปุ่มลูกศรขึ้น-ลง)
   - **ส่งทาง LINE ใน 1 คลิก**: มีเทมเพลตข้อความสำเร็จรูปพร้อมลิงก์ส่งให้ลูกค้า และระบบสร้าง QR Code สำหรับพิมพ์ติดโต๊ะหน้าร้าน

3. **ป้องกันอาการจอขาว (White Screen) หลัง Deploy บน GitHub Pages 100%**
   - ตั้งค่า `base: './'` ใน `vite.config.ts` ให้โหลดไฟล์ Asset ได้ถูกต้องแม้ Deploy อยู่ใน Subdirectory
   - ไม่ใช้ BrowserRouter ที่จะทำให้เกิด Error 404 เวลาลูกค้ากดรีเฟรชหน้าเว็บ
   - มีระบบ Error Boundary ดักจับข้อผิดพลาด

---

## 🚀 วิธีนำขึ้น GitHub Pages ฟรี 100%

1. สร้าง Repository ใหม่บน GitHub (เช่น ชื่อ `my-restaurant-menu`)
2. อัปโหลดไฟล์ทั้งหมดของโปรเจกต์นี้ขึ้น GitHub
3. ไปที่แท็บ **Settings** ของ Repository -> เลือกเมนู **Pages** ทางด้านซ้าย
4. ในส่วน **Build and deployment > Source** ให้เลือกเป็น **GitHub Actions**
5. ระบบจะทำงานและ Deploy เว็บให้อัตโนมัติในไฟล์ `.github/workflows/deploy.yml`
6. ได้ลิงก์เว็บเมนู เช่น `https://username.github.io/my-restaurant-menu/` นำไปส่งให้ลูกค้าทาง LINE ได้ทันที!
